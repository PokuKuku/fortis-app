# DarkBackgroundPreview

A dedicated component that isolates the background system used in the Strength Analytics Dashboard.

## Usage

```tsx
import { DarkBackgroundPreview } from '@/sd-components/ab7fa6e3-a8fd-4829-8f9e-9b2020ce7bbe';

function App() {
  return <DarkBackgroundPreview />;
}
```

## Components Included

1.  **StainlessSteelPattern**: The gradient and SVG texture base.
2.  **ParticleBackground**: The floating particle animations (the "shine").
