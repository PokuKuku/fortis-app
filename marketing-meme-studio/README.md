# Fortify Meme Studio

Local manual editor for Fortify meme images.

## Run

```bash
node marketing-meme-studio/server.mjs
```

Then open `http://127.0.0.1:4311`.

## What It Does

- Live-edit a single meme card
- Edit headline, subtitle, labels, layout, and gender
- Adjust every muscle tier manually for Body A and Body B
- Preview the render instantly
- Export the current meme as PNG

## Notes

- This tool lives outside `fortify-mobile-app`
- It reuses Fortify muscle mapping and body shape assets
- There is no AI generation flow in this version
